Build a complete, professional, responsive web application called:

STUDENT ATTENDANCE ANALYSIS SYSTEM

This is Version 1 of the project.

IMPORTANT:
The application must be focused ONLY on student attendance analysis using uploaded Excel files.

Do NOT add:
- Marks Analysis
- Supabase
- Google Maps
- Google Cloud
- AI chatbot
- Login/authentication
- Any external database

The application should process the uploaded Excel file directly in the application and generate attendance analysis, visualizations, and downloadable Excel reports.

==================================================
1. PROJECT PURPOSE
==================================================

The purpose of this application is to analyze student attendance subject-wise from an uploaded Excel file.

The user will:

1. Upload an attendance Excel file.
2. Enter/select the Academic Year.
3. Enter/select the Section.
4. Select the attendance analysis range:
   - Below 65%
   - 65% to 74%
5. Select the attendance date/sheet when required.
6. Click Analyze.
7. The application analyzes the Excel data.
8. Display student-wise and subject-wise attendance results.
9. Display counts and statistics.
10. Display graphs.
11. Allow the user to download the analyzed results as an Excel file.

8. ATTENDANCE VALUE HANDLING
==================================================

The sample Excel may contain attendance values represented as decimal ratios.

For example:

0.7941

should be interpreted as:

79.41%

0.5581

should be interpreted as:

55.81%

0.4242

should be interpreted as:

42.42%

If the Excel contains values already represented as percentages, handle them correctly as well.

The application must avoid incorrectly multiplying values that are already percentages.

Create robust percentage normalization logic.

Examples:

0.5581 → 55.81%

55.81 → 55.81%

"55.81%" → 55.81%

Blank/null/non-numeric values should not cause the application to crash.

AI (60.00%)

4

DWAV (74.00%)

Count:

3

75% exactly must NOT be included in the 65%–74% range.
